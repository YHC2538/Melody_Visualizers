🎹 User Manual

1. 設定參數 (Parameters)

點擊左上角的選單或使用側邊欄，設定音階(Scale)、調性(Key)與速度(BPM)。勾選 Arpeggios 可增加豐富度。

2. 生成音樂 (Generate)

點擊 "生成 MIDI" 按鈕，系統將透過演算法產生獨一無二的旋律。

3. 視覺化與導出 (Visualize)

生成後可預覽音訊，滿意後點擊 "渲染影片" 即可獲得視覺化 MP4 檔案。

4. 快捷鍵

Space: 播放/暫停
M: 靜音

Music Parameters Guide

了解每一個設定如何改變您的音樂氛圍。

Scale Modes (音階風格)

Major Scale

基礎大調。聽起來**明亮、快樂、充滿希望**。這是流行音樂中最常見的風格，給人正向的感覺。

Minor Scale

自然小調。聽起來帶有**悲傷、嚴肅或情感豐富**的特質。適合營造深沉、內斂的氛圍。

Blues

藍調音階。帶有**憂鬱、慵懶與靈魂感**。源自美國黑人音樂，常帶有獨特的切分音與情感宣洩。

Pentatonic Major

大調五聲。去掉了半音，聽起來**非常純淨、和諧、有東方色彩**。常聽起來像民謠或兒歌般單純。

Pentatonic Minor

小調五聲。這是**搖滾樂與電吉他獨奏**的靈魂。聽起來酷勁十足、充滿能量且不容易出錯。

General Settings (基礎設定)

Key (調性)
音樂的中心音高。例如 C Key (C大調) 以 Do 為中心。改變調性會改變整首歌的音域高低。
BPM (速度)
Beats Per Minute。數值越高 (如 140+)，音樂越**激昂快節奏**；數值越低 (如 80-)，則越**放鬆緩慢**。
Bars (長度)
樂曲長度。**4 小節**適合短旋律試聽；**16-32 小節**則是一段完整的樂章。
Arpeggios (琶音)
像流水一樣將和弦的音符**依序彈奏**，而不是同時按下。能增加音樂的流動感與裝飾性。
